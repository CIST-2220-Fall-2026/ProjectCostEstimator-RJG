# Project instructions

## Technical documentation lookup

Use Context7 for current documentation when a task asks about a library, framework, SDK, API, CLI tool, or cloud service. Resolve the library ID first, then query the relevant documentation. This does not apply to general programming concepts, business logic, refactoring, or code review.

## Writing standard

Follow ASD-STE100 Simplified Technical English, Issue 9, for all new or revised instructional material in this repository. Apply its writing rules and controlled dictionary to tutorials, presentations, speaker notes, captions, diagrams, and supporting text. Use short, direct sentences. Give one instruction at a time. Use active voice and the same term for the same concept throughout a lesson.

Keep exact code, API, product, and file names. Treat necessary C# and .NET MAUI terms as technical names. Do not change identifiers to force them into the controlled dictionary. Review the final text against the current official standard before delivery. Do not claim formal ASD-STE100 compliance unless the complete text has been checked against all applicable rules and dictionary entries.

Official source: https://www.asd-ste100.org/
