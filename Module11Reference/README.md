# Module 11 reference

This is the completed MVVM redo application. It uses the MVVM Toolkit, constructor injection, a JSON BOM service, and a MAUI interaction adapter. `Module11Reference.Tests` contains tests for persistence and view model decisions.

Build on Windows with `dotnet build Module11Reference/ProjectCostEstimator.csproj -f net10.0-windows10.0.19041.0`. Run the tests with `dotnet test Module11Reference.Tests/Module11Reference.Tests.csproj`.
